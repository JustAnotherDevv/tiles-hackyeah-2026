# acme-payments (demo workspace)

Small refunds service used in the **Aegis** Claude Code demo. Nothing here is real:
customer data in `data/customers_sample.csv` is fake (checksum-valid test values), `.env` is
generated by `demo/claude/reset.sh` with throwaway values.

- `src/payments/refunds.py` - refund calculation + customer letter rendering
- `data/customers_sample.csv` - sample customers (FAKE)
- `docs/SETUP.md` - developer setup

Run the tests with `python3 -m doctest src/payments/refunds.py -v`.
