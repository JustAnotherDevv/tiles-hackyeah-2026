## Chosen concept: **Aegis Pocket — Approve AI Agents** (companion to the Goldman project)
A native HarmonyOS (ArkTS/ArkUI) app that puts a human in the loop for AI agents: when an agent governed by the Aegis gateway (Claude Code, a local Ollama agent…) requests a risky action ("spend $50 on a SaaS subscription", "read the customers table", "raise the team budget"), the request appears as a **notification** on the phone/watch; the user **approves/denies** according to their role (member/admin/owner). A **home-screen service widget** (Form Kit) shows live AI security posture (blocked threats, redacted personal data, budget left). An on-device preview shows exactly what data would leave the device. Talks to the Aegis gateway REST/SSE API: `GET /api/approvals`, `POST /api/approvals/{id}/approve|deny`, `GET /api/events` (SSE), `GET /api/stats` (see `aegis/docs/CONTRACTS.md` + Addendum A for exact shapes) — with a built-in mock mode so it demos without the gateway.
Platform capabilities to showcase: Form Kit service widgets, Notification Kit (local notifications), wearable/watch target if feasible, ArkUI animations; privacy-first design.
Separate project from Aegis (own repo, own README/video/HackTribe entry) — the organizers discourage one project in two categories.
