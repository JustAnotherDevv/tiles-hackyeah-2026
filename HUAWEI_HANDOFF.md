# Huawei task — HANDOFF (start here for the HarmonyOS side)

Second priority after the Goldman Sachs project (`aegis/`, see `aegis/HANDOFF.md`). This parent folder `hackyeah/` is the **Huawei "Imagine What's Next"** submission repo (own git repo; `aegis/` is gitignored here).

## The task (Huawei partner challenge, 25,000 PLN: 12k/8k/5k)
Build a system feature or mobile app for an **OpenHarmony-based device** (HarmonyOS / OpenHarmony / Oniro). Must: target **API 20+** (Compatible SDK 6.0.0(20); organizers: compile API 23, target API 24); run on an emulator or device; deliver a **working .hap**; **public repo**; reproducible setup/build/install/launch instructions; brief recorded demo; architecture description; **AI_WORKFLOW.md** (mandatory if AI tools used — we use Claude Code/Opus 5.5 with parallel sub-agents).
Judging: originality 20, demonstrated usefulness 20, technical execution 20, **use of platform capabilities 20** (an app that runs unchanged on any OS scores lower), demo 10, reproducibility 10. Themes: Intelligent Experiences, Spatial, Human-Centric. Full brief: `TASKS.md` (Huawei section) and the organizers' repo https://github.com/onirodeveloper/hackyeah2026-challenge (README, FAQ, `hackathon_challenge.md`).

## Chosen concept: **Tiles: A Phone That Adapts** (pivot Sun 4 Oct ~06:45; replaces Aegis Pocket)
A native HarmonyOS (ArkTS/ArkUI, API 20+) phone home that reshapes itself around the person using it. The home is a grid of **big, colourful, live tiles** (each a small actionable card: "Pills 8:00, tap when taken", "Call Kasia", "14° and rain, take the umbrella", "Homework 3 of 5", "Dinner Fri 19:30 at Veganda, vote"). An **Ask Tiles** assistant turns requests into new tiles: **generative UI**, the assistant emits a structured `TileSpec` (layout, colour, blocks, actions) rendered natively. Today the generator is an **on-device, deterministic EN/PL intent planner** (no LLM, no network; say so). The app **adapts per profile** (Senior Halina 78, Kid Zosia 8, Low vision Michał, Everyday Daniel 29) and from use (missed taps → "text 40% bigger?"); for senior/kid a **caregiver/parent approves** every change and every assistant tile (Caregiver screen = "Kasia's phone" simulation). **Guardian** scam shield for seniors (simulated "Demo call", red flags → "This looks like a scam. Hang up. Kasia already knows.").
Themes: **Human-Centric** (lead) + **Intelligent Experiences**. Source of truth: `docs/TILES_SPEC.md`. Platform capabilities: Form Kit widgets (Next up 2x2, My tiles 2x4, Big buttons 4x4), Notification Kit (pill notifications, caregiver + Guardian alerts), `reminderAgentManager` (rejected with 1700002 without an AppGallery entitlement → in-app timer + notification fallback only while the app runs; never claim background reminders), read-aloud (Accessibility Kit announcement via the screen reader + visible "Speaking…" state; Core Speech Kit is HarmonyOS-SDK only), vibrator haptics, dialer via Telephony Kit / Want, ArkData Preferences, accessibility + dark mode. Bundle `com.hackyeah.tiles`.
Separate project from Aegis (Goldman entry in `aegis/`); the organizers discourage one project in two categories.
Why the pivot: team decision that Aegis Pocket (an approvals companion for AI agents) was the wrong concept for this challenge. Its docs/media are kept and marked superseded (`docs/HACKTRIBE_POCKET.md`, `docs/video/aegis-pocket-*`, `docs/screenshots/0*.jpeg`, `docs/deck/AegisPocket_*.pdf`).
