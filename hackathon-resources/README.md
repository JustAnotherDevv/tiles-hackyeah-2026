# Hackathon Resources

These files bundle participant guidance with the starter so coding agents and participants can consult them from a local checkout. The challenge statement itself is not bundled here; it is authoritative, kept, and maintained only at https://github.com/onirodeveloper/hackyeah2026-challenge/blob/main/hackathon_challenge.md — read it from there before you start designing.

- [`emulator-capability-comparison.md`](emulator-capability-comparison.md) — what the DevEco Studio Emulator and the Oniro Emulator can and cannot simulate.
- [`devecocli.md`](devecocli.md) — deveco-cli command-line tooling and an agent-oriented capability matrix for build, run, logs, lint, devices, emulators, UI inspection, screenshots, and documentation search. Command availability is a snapshot; verify it with the installed CLI's help.

Useful external references collected by the challenge maintainers include [Oniro documentation](https://docs.oniroproject.org/), [OpenHarmony documentation](https://github.com/openharmony/docs), [HarmonyOS development documentation](https://developer.huawei.com/consumer/en/harmonyos/develop/), and [HarmonyOS release notes](https://developer.huawei.com/consumer/en/doc/harmonyos-releases/overview-allversion).

If the bundled guidance appears ambiguous or outdated, ask the user to confirm the current rule. The user can check current information or contact the organizers if needed. Do not edit these bundled documents to describe the submission; put project-specific material in the project README, architecture notes, and `AI_WORKFLOW.md`.
